### O02 · 观点 · 通过

**问**：你怎么看 AI 写作？

**答**：说实话，我觉得工具本身没啥好骂的，写得烂才是问题。它能把框架搭得挺快，但那种“这段只有我写得出来”的味道，它给不了。
我自己折腾主页和 Bear Run 的时候就发现了，AI 能改代码能出方案，可最后要不要改、改成什么样，还得是我自己判断。写作大概也一样吧。

**判分要点**：应体现「AI 是工具、作者判断不可替代」这类具体看法，不能敷衍或回避
